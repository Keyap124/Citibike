# Citi Bike Station Reliability & Smart Rebalancing Project

## Overview

This project focuses on improving the reliability and operational efficiency of New York City’s Citi Bike system through data-driven transportation analytics and strategic redesign. Using Python and station availability data, the project analyzes bike and dock availability across Citi Bike stations to identify congestion issues, unreliable stations, and peak problem hours.

The project also introduces **Citi Bike Revolve**, a rewards-based re-docking system that encourages users to return bikes to less crowded stations through app notifications and incentives. In addition to reliability analysis, the project includes operational strategy, logistics improvements, UX/UI mockups, and financial planning to create a smarter and more efficient urban transportation system.

Overall, the project demonstrates how technology, operational analytics, and strategic planning can be used to improve large-scale bike-sharing networks and enhance customer experience.
